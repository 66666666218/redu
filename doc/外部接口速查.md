# 外部接口速查

> **为什么有这份文档**(2026-10-03):那天为了"补几个活跃群",我先猜 `group/search` 的参数
> (**试了 60 多种形状全 400**)、又去解 APK(结果是**加固壳**:桩 dex 只 21KB/7 个类,字节码拿不到)、
> 又扫群号附近(全是 2 人私聊群)、又找退群接口(不存在)—— **绕完才发现答案一直躺在
> `xunlei_kouling.resolve()` 里**。**问题不在代码,在于没有一份"哪个接口在哪、长什么样"的索引。**
> 这份文档就是那个索引;**新增/改动外部接口时请回来更新它**(和 `doc/API.md` 同级要求)。
>
> 各模块的**详细报文样例与踩坑记录**仍写在对应源码的模块 docstring 里(本文给出位置),
> 本文只做**索引 + 最容易忘的坑**。

### 1.1 群组(chitchat)

```text
GET  {_BASE}/chitchat/v1/group/list        账号所在的全部群
GET  {_BASE}/chitchat/group/records        ⚠️ **没有 v1**,且**只有 GET**(POST 一律 404)
POST {_BASE}/chitchat/v1/group/query       单个群信息(不登录也能查,凭 group_id)
POST {_BASE}/chitchat/v1/group/join        ⚠️ group_id **必须传数字**,传字符串报 201
GET  {_BASE}/chitchat/group/sessions       聊天会话(与 group/list 同集合)
POST {_BASE}/chitchat/v1/group/member/query 群成员
```
`_BASE = https://api-shoulei-ssl.xunlei.com`,详见 `xunlei_group.py` 模块说明。

**四个必记的坑**:
1. **每页只回 20 条**(`count` 传更大也没用),翻页用 `record_id` 游标 + `direction=1`(**往更旧翻**,已实测);
   只拉最新一页会**静默丢消息**(见 `_records_with_catchup`)。
2. **没有退群端点** —— `group/quit|exit|leave|member/*` 全 404。加群是**单向**的,只能去 App 手动退。
3. **`/chitchat/v1/group/search` 存在但参数未知**:返回 `400 code:201` 而非 404,说明路由在;
   但试过 keyword/key/word/q/query/searchKey/超集 body/查询串/表单/camelCase/路径参数 **全 400**。
   **别再去猜它** —— 需求(群名 → 群号)用下面那条 `associate_search` 就够了。
4. **同名群并存**:`三岁分享`=1550069837 而 `三岁分享2`=1556104079 —— **别拿群名当唯一键**。

### 1.2 口令 / 群名解析(⭐ 最容易忘的一条)

```text
GET {_BASE}/xlppc.searcher.api/v3/associate_search?keyword=<词>&guid=<device_id>
      → resp["birdkey"]["action_url"] 里含 group_id= 或 share_id=
```
* 代码:`xunlei_kouling.resolve()`;
* **《群名》会被解析成 `kind="group"` + `group_id`**,`ingest()` 随即 `join_group()` ——
  **"抖音《群名》→ 自动加群"整条链就是它**,别再另找"搜群接口";
* `/xlppc.searcher.api/v1/search` 也存在,但要账号参数(回 `无效的数字账号`),**不用它**。

### 1.3 群邀短链

```text
https://dlj.8uri.cn/dlj/<8位码>  --302-->  https://sj-m-ssl.xunlei.com/group-invite?from_uid=&group_id=&type=url
```
邀请页是 **Nuxt SSR,无需登录**,群名/群号写在 `__NUXT__` 里;`8uri.cn` 本身是"迅雷短网址"服务。

### 3.1 MediaCrawler 系(小红书 / 快手 / 微博 / 贴吧 / 抖音 / B站)

这六家**带 Cookie 直连过不去**(微博 `ok:-100`、贴吧 403、小红书/抖音要请求签名),
只能走 MediaCrawler:`app/services/mediacrawler_source.crawl(platform, keywords)`。

* ⚠️ **独立 venv + 绝对路径**(`tools/MediaCrawler/.venv`),且**一次浏览器跑完所有关键词**;
* 贴吧等平台**需要先手工登录一次**(档案 `browser_data/cdp_<平台>_user_data_dir`,
  见 `tools/tieba_login.py`);未登录会卡扫码直到超时 → `MediaCrawlerError`;
* **实测命中率**(2026-10-03,同一批词):**贴吧 56%** > 知乎 17.8% ——
  所以"公开发现链"以**贴吧为主源**(`PAN_DISCOVERY_TIEBA`)。
