## 二、已落地的策略:推送去重窗口

`push_ledger.drop_recent()` + `PUSH_DEDUPE_HOURS=24`(0=关):

- **只在本板块内去重** —— 不同板块的群不是一批人,跨板块去重会把别的群饿死;
- 接在 `resource_presence`(B站/微博/小红书/快手/贴吧/知乎)与 `douyin_leads`、`pan_discovery`;
- 放在 AI 筛选**之前**(先省钱);
- 卡头写「已跳过 N 条 24 小时内推过的」,运行记录也写「h 内已推过」——**不静默**。

按上表估算,这一刀会砍掉 B站约一半、抖音约六成、微博/小红书/快手/贴吧三到四成的**重复行**。

## 五、新鲜度闸门(2026-10-29,「全部都需要新鲜度检查」)

**统一规则**(`app/services/freshness_gate.py`):

- 推送前按**发布时间**裁,`PUSH_FRESH_DAYS`(默认 **7 天**)以外的不给客户看;
- **判不了时间的放行**并单列计数(把"不知道"当"老"会把整条板堵死);
- 卡片与运行记录写 `新鲜 8/12(无时间 3)` —— 不写的话「这个板全是旧货」与「这个板没内容」同形;
- 它**只决定推什么**,不改采集/转存闸门(`pan_discovery_max_age_days` 仍是独立的一道)。

**接在哪些板块**:跨平台资源热度(逐平台)、公开平台(知乎/贴吧盘链)、抖音线索。
**时间从哪来**:跨平台热度的条目取**本轮最新一条命中**的发布时间;公开平台取原帖发布时间;
抖音本来就有 `publish_at`。**拿不到时间的平台**(部分源的搜索接口不给时间)会显示「无时间 N」——
这正是下一步要补的:没有时间就没法做新鲜度检查。

⚠️ 预期效果:**知乎会最先"缩水"** —— 它 7 天内的资源只占 6.5%,闸门一开几乎不剩。
这不是 bug,而是把「知乎供给本来就旧」这件事**显式化**;要让它重新有量,得换/加新源,
而不是把闸门关掉。

## 八、资源类型分类:覆盖与改进(2026-10-29,用户问「不同类型的资源是否能分类」)

**改前实测**:
- 抖音线索(近 500)能分出类 **76%**;
- **资源库(1647 条)只有 12% 分得出类** —— `其他` 1445 条,因为库里大量是**剧名**
  (`《烟疤》02` / `《侍君》5` / `塞雷卡2`),本身没有类目词;
- 推送台账(近 1000)**其他 49%**。

**根因**:名字没类目词,但**放在哪个文件夹里**就是答案 ——
`男频《漫剧合集》` 下 169 条全是漫剧、`X开头游戏` 下全是游戏。分类只看了名字。

**改法**(`category_topics.type_of` / `subtype_of` / `display_niche`):

1. `type_of(name, parent)`:先按 `classify(名字 + 父目录)` 判;**父目录里的通用词先剥掉**
   (否则 `摆烂系列合集` 的「合集」会给资料白送 1 分、把整批剧判成资料 —— 实测踩到);
   仍判不出再看父目录提示词(漫剧/男频/系列 → 影视;游戏/宝可梦/gta → 小游戏;模拟器/解压 → 软件)。
2. `subtype_of`:影视细分成 **漫剧 / 动漫 / 短剧 / 电影 / 电视剧**(只看词面,不影响轮换)。
3. `display_niche`:推送卡**按细分类型分组** —— 漫剧和短剧是两条生意,不能再混成「影视」。

**改后覆盖**:

| 数据 | 改前 | 改后 |
|---|---|---|
| 资源库(1647) | 分得出 12% | **73%**(影视 847 / 小游戏 265 / 软件 81 / 资料 10 / 大瓜 4) |
| 抖音线索近 500 | 影视 316 / 其他 118 | **漫剧 223** / 其他 118 / 影视 67 / 软件 33 / 资料 20 / 动漫 16 / 短剧 8 / 小游戏 7 / 大瓜 4 / 问卷 2 / 电视剧 2 |

**仍判不出的 27%**:主要是「最全文件」这种**大杂烩目录**下的裸剧名 —— 父目录不带类型、
名字也没有类目词。要再提高得靠**内容特征**(如“第N集/N分钟/N集完结”这类结构词)或人工标注,
不是再加几个关键词能解决的。

## 十、结构词分类(2026-10-29 晚,「然后再进行下一步结构词」)

**判据**:一个类目词都没命中时,标题里的**连载结构**就是证据 ——
`第N集 / 全N集 / 共N集 / N-M集 / 番外 / 大结局 / 更至N / 更新至N / 第N季 / 裸 N集`。

**两条边界(实测踩过)**:
- **不认裸 `N季`**:`2026赛季`、`四季度` 会被误判成影视 ⇒ 只认「第N季」;
- **游戏父目录要先于影视判**:`王国保卫战全系列版本` 同时含「系列」(影视提示)与
  「全系列版本」(游戏)—— 按表序会把整个游戏系列判成影视 ⇒ `_PARENT_HINTS` 把**小游戏放最前**。

**覆盖变化**:

| 数据 | 只有父目录 | + 结构词 |
|---|---|---|
| 资源库(1647) | 分得出 73%(未分类 440) | **85%**(未分类 **245**;影视 989 / 小游戏 318 / 软件 81 / 资料 10 / 大瓜 4) |
| 抖音线索近 500 | 其他 118 | 其他 **99**(影视 86 / 漫剧 223 / 动漫 16 / 短剧 8 …) |

**剩余 15% 未分类**:`《烟疤》02` 这种**连集数都没有**的裸剧名 —— 没有结构证据、
也没有类目词,继续提高只能靠**标题之外**的信息(作者/所属账号的历史类型)。

## 十一、同批次上下文分类(2026-10-29 晚,「可以开始」)

**做法**:一个名字单独看判不出时,看**同一个文件夹里兄弟条目的多数类型**
(`type_of(..., siblings=同目录)`),门槛 **≥3 票 且 ≥70%**。

**实测依据**:`最全文件` 下 87 条可判的里 **83 条是影视(95%)**,而同目录还有 124 条判不出。

**两条护栏**:
- **附件/说明类不参与**(`简介.doc` / `压缩包怎么使用.mp4`):它们不是资源内容,
  被邻居带成影视只会让统计变脏;
- 票数不足或多数票 <70% 就**弃权**(不猜)。

**覆盖**:资源库未分类 **245 → 126**(分得出 **92%**:影视 1108 / 小游戏 318 / 软件 81 / 资料 10)。

**接线**:`search_keywords` 会把库里名字按「名字+父目录+同目录」判一次,通过
`pick(cat_of=...)` 交给轮换 —— 理论上"影视轮优先出剧名、小游戏轮优先出游戏名"。
⚠️ **今天实测对出词没有可见变化**:那批裸剧名本来就**不在候选池**(池子取的是最近 50 个
资源名,且它们多在老目录)。⇒ 这次收益主要在**分类覆盖/统计**,出词收益要等这些名字
进入候选池后才会体现。
