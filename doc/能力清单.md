# 能力清单

> **这份文档回答一个问题:"这个系统能做什么、入口在哪、怎么触发、上次真跑通是什么时候"。**
>
> **为什么有它**(2026-10-04):当天两次"重新发现"的共同点,不是忘了代码怎么写,而是
> **不知道系统已经有这个能力** —— 群名→群号的解析一直躺在 `xunlei_kouling.resolve()` 里、
> 贴吧的盘链能力一直被一条写错的结论挡着。接口速查解决"怎么调",这份解决"**有什么**"。
>
> ⚠️ **"上次真跑通"不要手写进表里**(写进去必然过期)。跑:
> ```sh
> python scripts/capability_report.py     # 从心跳/运行记录/业务表现取,并标出判据来源
> ```
> 表里只维护**代码推不出来的那部分**(入口、触发方式、有没有测试、坑)。

## 维护约定

1. **新加能力 → 回来加一行**(哪怕只写入口和触发)。
2. **能力下线/被取代 → 把这行删掉**,别留着(留着就会像"贴吧没有盘链"那样骗人)。
3. 表里**不要写时间**;"上次真跑通"一律跑 `scripts/capability_report.py` 现取。
4. 踩过的坑写进**备注**列 —— 尤其是"**别再试**"那类(负面知识同样值钱)。
