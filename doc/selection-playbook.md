# 网盘拉新选题手册（v2.3.0，2026-10-01）

> 回答两个核心命题：**什么样的热点适合做网盘拉新**、**监控到之后如何利用**。
> 系统侧的自动判据实现：`app/services/niche_fit.py`（规则可解释、可回测、可调词表）。

## 一、什么样的信息适合做网盘拉新

网盘拉新的机制：**用户为拿一份文件必须转存你的夸克链**。所以判据只有一问的变体：
**"这个热点背后，有没有一群人此刻非要一份文件不可？"**

### 四问判据（系统自动打分，输出 strong/mid/weak）

| # | 判据 | 命中示例 | 权重 |
|---|---|---|---|
| ⓪ | **平台人群是否天然需要文件** | B站（游戏/二次元：壁纸/攻略/素材）、豆瓣（影视：合集/清单）、掘金（技术：源码/工具包）、知乎（学习资料）→ 可衍生高；微博/36氪（泛资讯）→ 低 | **核心 0.35~0.55** |
| ⓪b | **热点类型是否指向"要文件的人"** | 游戏（原神/新番）、影视剧集、考试（考研/考证）、软件工具 → 加分 | 0.15~0.25 |
| ① | **标题是否自带资料形态词** | 真题/课件/模板/安装包/壁纸/攻略/赛程/名单/报告 | 0.30~0.55 |
| ② | **是否含搜索意图词** | 求资源/完整版/下载/哪里能看/整理 | 0.15~0.25 |
| ④ | **盗版整套信号（降权封顶）** | 全集/4K/蓝光/破解/网课——可做但高危，压级不优先推 | 封顶 0.5 |

**实测案例（2026-10-01 真实热榜）**：
```
🎯 0.70 《原神》六周年主题曲(B站)     → 做壁纸/素材包,人群精准
🎯 0.60 GPT-6 玩《我的世界》(知乎)    → 做 AI 工具教程/安装包
🟡 0.50 年会不能停！2(豆瓣)           → 职场电影合集/台词金句图
⚪ 0.20 天安门广场国庆升旗仪式         → 纯围观,无文件可交付,挡在选题之外
⚪ 0.10 热门中概股美股盘前普涨(36氪)   → 同上
```

### 验证品类层（2026-10-01，用户一线业务事实）

用户实际赚过的品类直接编码为**强信号**（+0.35，高于泛形态词）：
**资料 / 影视 / 漫剧 / 问卷（含人格测试、直达入口类）/ 大瓜（聊天记录·截图·爆料）**。

### 回灌校准（对标号即最大样本库）

结算反馈只能用自己的发文（样本少、慢）；**142 个对标号的每一篇资源文都是
"同行验证过什么赚钱"的活数据**。工具：`python scripts/analyze_proven_categories.py --days 60`
——输出品类分布 + **盘链共振榜**（同盘链被多少号同发 = 需求被反复验证的强度）。

**2026-10-01 回灌实证（523 篇/206 条共振链）**：
```
品类分布: 影视 48% | 资料 31% | 问卷 4% | 未分类 17%
共振榜:  花少2人格测试 ×13 | 审批小程序 ×12 | 中文字体 ×8 | 霸王茶姬教程 ×7 | 七宗罪测试 ×6
```
**读法**：影视量大→竞争也密；**测试/问卷/小工具/素材量小但共振极强**（需求被反复验证）——
"共鸣度"据此校准：问卷类词表已按此扩充（人格测试/入口/直达/自取）。

### 关键认知（踩过坑总结）
- **资料形态常是"衍生"的**：热榜标题是新闻式的（"《原神》六周年主题曲"），但人群需求可衍生（同好要壁纸/素材）——**平台人群 + 热点类型才是主判据**，标题词只是加分。
- **区分两类热点**：**用户自选的监控词**（已表达跟随意向）直通不拦；**系统自动发现的热榜条目**才过适配度筛选——宁缺毋滥。
- **高危≠不做**：影视全集类需求真实但版权风险高（我们有过霸王茶姬版权清扫的实测教训），压级做长尾低风险包装，不抢时效。

## 二、监控到之后如何利用（五步路径）

系统对每条通过筛选的建议，自动生成**教学式方案**（LLM 输出 `_plan_text` 五段）：

1. **【为什么能做】**——需求缺口一句话（对应判据①的证据）
2. **【做什么】**——具体到文件内容的资料清单 + 发布标题（带时效词/人群词）
3. **【给谁】**——谁非要不可 + 转存钩子（为什么必须转存）
4. **【时机】**——热点发酵窗口（几小时内动手/热度还能持续几天）
5. **【三步走】**——搜素材 → 整理打包 → 挂链发布（教新手落地）

### 闭环
```
热榜/监控词 → 适配度筛选(本节一) → LLM 五步方案 → 总群/选题卡
→ 员工执行发文 → 系统自动归因(发文数据反推) → 盘链扩散结算 → 复盘哪类热点真赚
```
**闭环止于"复盘",再往前一步是人工的** —— 见下面这条口径修正。

**复盘口径(2026-10-03 修正,此前本文写成了"已实现")**:
> 原文写的是"连续结算为 0 的热点形态下次降权;高扩散的加码跟进" —— **这个自动机制目前不存在**。
> 实际有的是:① `weekly_review` 的**复盘展示**(哪类真赚,给人看);② 建议的机会分与
> `niche_fit` 的品类权重 (`PROVEN_CATEGORIES`) **都是人工校准**的常量;
> ③ 结算信号 (`repost_gain` 盘链扩散增量) 只聚合展示,**没有任何代码把它回灌成权重**。
>
> **为什么还没做**:链接级真实转存数在夸克/迅雷侧**都拿不到**(2026-09-29 定案),唯一的真值
> 入口是**人工周录**(`pan_recruit_weekly`,分渠道)。2026-10-03 加了「**线索结算对账**」
> (`GET /api/hotspot/leads/settlement`,建议页可见):把**系统侧量级**(线索数/转发量)
> 与**你录的真值**按周并排 —— 但两边**口径不同源**(转发量是别人视频的,你录的是自己号的),
> 所以**只做趋势对照,不做自动相除校准**。等几周偏差稳定了再谈自动回灌。

`doc/architecture.md §4b` 是数据管线，本文是**判断与行动的手册**。
